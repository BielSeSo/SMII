1) Ejecutar directamente ./build_all.sh para que haga autodiagnostico de la compilación. En caso de que el ejecutable de problemas utilizar "sudo chmod +x build_all.sh".

2) Una vez el programa haya instalado las líbrerias necesarias se puede o volver a ejecutar el .sh o hacer un make all.
